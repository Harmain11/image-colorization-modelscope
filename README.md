# Image Colorization ModelScope Pipeline

## Overview  
This notebook demonstrates how to perform image colorization using the ModelScope pipeline. It loads a pretrained colorization model to convert grayscale images into color images, saving the result using OpenCV.

## Features  
- Installation of required libraries (`modelscope` and `addict`)  
- Usage of ModelScope’s image colorization pipeline  
- Saving output images with OpenCV  

## Tech Stack  
- Python  
- Jupyter Notebook / Google Colab  
- ModelScope  
- OpenCV  
- Addict  

## How to Use  
1. Install the required packages with pip.  
2. Import necessary libraries and load the colorization pipeline.  
3. Provide the path to your grayscale image.  
4. Run the pipeline and save the colorized output image.
